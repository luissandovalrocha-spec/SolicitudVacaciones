# Starter del componente

Esta versión es deliberadamente incompleta pero mantiene sintaxis válida. Los
`TODO 1` a `TODO 5` corresponden a los checkpoints del taller.

Para usarla, reemplaza temporalmente el bundle de `force-app` con estos archivos
en una copia o rama de trabajo. La solución completa permanece en:

`force-app/main/default/lwc/vacationRequestFlowScreen`

No edites el cálculo para convertir la regla de 15 días en una política real:
es únicamente una restricción didáctica del ejercicio.
